🎤 Closest Speaker Detection System

An interactive guide to understanding and using the system.

Project Overview

This project is a complete system for detecting the closest speaker to a microphone by analyzing audio intensity and voice activity from multiple audio sources. It consists of a Python-based WebSocket server and a web-based client interface, working together to provide real-time speaker analysis.

How It Works

Core Features

  • Real-time Audio Processing

    Handles audio streams from multiple clients concurrently.

  • Voice Activity Detection (VAD)

    Uses WebRTC VAD for efficient voice detection.

  • Audio Intensity Measurement

    Ranks speakers by proximity using decibel levels.

  • Speech Transcription

    Integrates with the Google Speech API to transcribe speech.

  • WebSocket Communication

    Enables real-time, low-latency communication.

Get Started

You will need **Python 3.x** installed on your system.

  1. Clone the repository from GitHub:

    git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

  2. Install dependencies using `pip`:

    pip install -r requirements.txt

  1. Start the server:

    python main.py

    The server will start on `localhost` at port `8765`.

  2. Open the client interface:

    Open the `index.html` file in your web browser. You can do this by simply double-clicking the file or by serving it via a local web server (e.g., `python -m http.server`).

  3. Connect and Record:

    • In the web interface, click the **"Connect Server"** button. Your browser will prompt you to grant microphone permissions.
    • Once connected, click **"Start Recording"** to begin the audio processing.
